THE NON-OBVIOUS ANGLE

Forecast → Uncertainty → Optimize → Act → Explain → Measure

01

Forecast

Clear-sky geometry × cloud field 32×32 advected by wind vector (phase correlation). Demand multi-site with temp sensitivity. P10/P50/P90 bands.

02

Uncertainty

Variability index ramp-risk per hour. Attention summary + feature importance. MAPE 7.8% solar, 8.2% demand, pinball loss.

03

Optimize

Tabular Q-learning price threshold + rolling-horizon LP safety (linprog). Guarantees SoC 100%, transformer limit, cycle limits. λ CO₂, μ peak sliders.

04

Act

Human-in-loop approval queue. Operator approves EV shift, black-start step. Logged with KPI impact. LLM never controls grid.

05

Explain

Every output has drawer: top drivers, counterfactual “what if immediate”, confidence, data source live/synthetic, model version.

06

Measure

SQLite ledger logs cost, CO₂, peak. Marginal vs average methodology. Export CSV + printable report. Proof of savings.
